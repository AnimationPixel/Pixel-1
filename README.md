**Un sistema operativo independiente desarrollado desde cero por Animation Pixel.**

Pixel 1 es un proyecto experimental de sistema operativo que cuenta con un kernel propio, arquitectura x86 de 32 bits y un formato nativo para ejecutar aplicaciones y juegos.

El objetivo es construir una plataforma independiente, con sus propias tecnologías y herramientas.

---

## Características

- **Kernel propio:** desarrollado en C y ensamblador.
- **Arquitectura:** x86 de 32 bits.
- **Arranque:** soporte de arranque BIOS.
- **Gráficos:** inicialización gráfica mediante VBE.
- **Formato nativo:** compatibilidad experimental con ejecutables `.px` y `.pixel`.
- **KAPI:** interfaz propia para las aplicaciones.
- **Juegos:** incluye proyectos creados para el ecosistema Pixel 1.

## Arquitectura

Pixel 1 está diseñado como un sistema independiente, con componentes propios:

| Componente | Descripción |
|---|---|
| Kernel | Núcleo del sistema operativo |
| PXG1 | Formato de ejecutables nativo |
| KAPI | Interfaz de aplicaciones |
| Pixel Runtime | Entorno de ejecución experimental |

## Estado del proyecto

Pixel 1 se encuentra en desarrollo. Algunas características todavía son experimentales y pueden cambiar durante su evolución.
